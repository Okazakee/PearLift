## Fonts

PearLift uses Space Grotesk through `@expo-google-fonts/space-grotesk`.

- Package: `@expo-google-fonts/space-grotesk`
- Upstream repository: `https://github.com/expo/google-fonts`
- Package license declaration: `MIT AND OFL-1.1`

If the website ships self-hosted font files, keep the corresponding font license files with the deployed site assets.
